# MLAY FARM — Meat Chicken & Flock Batch Management System

Dedicated meat chicken and broiler farm management system for **MLAY FARM**.

## Quick Start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000 in your browser!

## Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit of MLAY FARM"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mlay-farm.git
git push -u origin main
```
